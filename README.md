# Қазақша Ойна 🇰🇿 — казахский язык играючи

Веб-приложение (PWA) для изучения казахского языка русскоязычными пользователями.
Работает на Android и iPhone, устанавливается на главный экран как обычное приложение и работает без интернета.

## Режимы (8)
| | Режим | Суть |
|---|---|---|
| 📚 | Карточки | Переворачивай карточку, отмечай «Знаю» / «Ещё учу» |
| 🎯 | Найди перевод | Выбери правильный перевод (на «Продвинутом» — с таймером) |
| 🔤 | Составь слово | Собери казахское слово из букв |
| 🃏 | Найди пару | Мемори: карточки сначала показываются, потом закрываются — найди пары каз ↔ рус |
| ⚡ | Правда или ложь | Скоростной режим на время |
| 🔗 | Соедини пары | Соедини казахские слова с переводами |
| 🎈 | Лопни шарик | Лопни шарик с правильным словом, пока он не улетел |
| ✍️ | Буквы Ә Қ Ү | Вставь пропущенную казахскую букву + подсказка о произношении |

**Уровни:** 🌱 Начальный · 🌿 Средний · 🌳 Продвинутый (190 слов и фраз).
**Геймификация:** XP и уровни со званиями, монеты (тратятся на подсказки), комбо-множитель, жизни, звёзды за каждый режим, цель дня, серия дней, 13 достижений, конфетти, звуки, вибрация. Прогресс сохраняется на телефоне.

## Как опубликовать на GitHub Pages
1. Создайте репозиторий на GitHub (например `kazaksha`) и загрузите в него **все файлы из этой папки** (включая папку `icons`), чтобы `index.html` лежал в корне.
2. Откройте **Settings → Pages**, в разделе *Build and deployment* выберите **Deploy from a branch**, ветку **main** и папку **/(root)** → **Save**.
3. Через 1–2 минуты приложение будет доступно по адресу `https://ВАШ-ЛОГИН.github.io/kazaksha/`. Этой ссылкой и делитесь.

## Как установить на телефон
- **Android (Chrome):** откройте ссылку → кнопка «Установить» в приложении или меню ⋮ → «Добавить на главный экран».
- **iPhone (Safari):** откройте ссылку → кнопка «Поделиться» ⬆️ → «На экран „Домой“».

## Как добавить слова
В `index.html` найдите массив `RAW`. Каждая строка — категория: `[уровень, 'Категория', 'эмодзи', 'каз|рус|эмодзи;каз|рус|эмодзи']`.

## Обновление приложения
После изменения файлов увеличьте версию в `sw.js` (`kazaksha-v1` → `kazaksha-v2`), чтобы у пользователей подтянулась новая версия.
